# 주식 차트·시황·동향 자동 분석 (초안)

## 주식 앱 (맥: app.command 더블클릭)
브라우저에서 열리는 주식 앱입니다. 끄려면 실행 중인 터미널 창을 닫습니다.

| 메뉴 | 내용 |
|---|---|
| 시장 현황 | 지수 시세, 종목 등락 분포, 투자자별(개인·외국인·기관·연기금) 순매수, 상승률·하락률·거래대금·시총·거래량 순위 |
| 종목 상세 | 종목 검색, 현재가·시고저·52주 고저, 캔들 차트(일·주·월봉, MA·BB·거래량·RSI·MACD), 투자자 동향·외국인 지분율, PER·PBR·배당, 기술적 분석, 뉴스, 관심 추가·가격 알림 |
| 투자자 매매동향 | 시장별 투자자 일별 순매수, 투자자별(외국인·기관·연기금 등) 순매수·순매도 상위 종목 |
| 관심종목 · 알림 | 관심종목 시세·1개월 추이, 가격 도달 알림(앱을 열 때 알림 표시) |
| 보유종목 | 보유 수량·평균단가 입력 시 평가금액·손익·수익률·오늘 손익·비중 |
| AI 추천 | 수급 조건까지 포함한 기법 조합 백테스트로 1개월 추천 종목·목표가·손절가 |
| 시황 리포트 | HTML 리포트 생성·보기·내려받기 |
| 설정 | 데모 모드, KRX 계정 |

- 투자자별 매매동향·외국인 지분율·PER/PBR은 한국거래소(KRX) 데이터로, **data.krx.co.kr 무료 회원가입 후 설정 메뉴에 아이디·비밀번호 입력**이 필요합니다. 입력 후 앱을 껐다 켜면 적용됩니다.
- 실시간 호가·체결, 주문 기능은 증권사 Open API 연동이 필요해 포함하지 않았습니다.
- 같은 와이파이의 휴대폰에서 쓰려면: 앱 실행 후 터미널에 표시되는 Network URL(예: http://192.168.0.5:8501)을 휴대폰 브라우저로 엽니다.

## 핵심 기능 — 1개월 추천 종목
- 코스피·코스닥 시가총액 1조 원 이상 종목 전체를 3년치 시세로 스캔
- 기본 조건 23개(추세·모멘텀·돌파·눌림·반전·거래량·캔들·시장국면)를 1~3개씩 조합한 2,047가지 기법을 과거 데이터로 백테스트
- 신호 다음 날 시가 매수, 목표가 익절 / 손절가 손절 / 20거래일 경과 시 종가 매도, 거래비용 0.25% 차감
- 학습(앞 65%)·검증(뒤 35%) 구간 모두에서 수익이 유지된 기법만 채택
- 오늘 신호가 새로 발생한 종목을 기법 승률 순으로 추천하고 목표가·손절가(ATR 배수, 기법별 최적화) 제시
- 첫 실행은 약 350개 종목 시세를 받느라 5~10분 걸릴 수 있음. 같은 날 재실행은 cache 폴더를 사용해 빠름
- 빠르게 시황만 보려면 `python main.py --no-scan`

주요 지수와 관심종목 시세를 받아 기술적 지표를 계산하고, 추세 판정·매매 신호·시황 요약과 차트를 담은 HTML 리포트를 자동 생성합니다.

## 맥(macOS) — 더블클릭 실행
| 파일 | 용도 |
|---|---|
| install.command | 최초 1회 설치 (.venv 전용 환경 생성) |
| demo.command | 가상 시세로 연습 실행 |
| app.command | 주식 앱 실행 |
| run.command | 실제 시세로 리포트 생성 후 열기 |
| schedule_on.command | 평일 16:10 자동 실행 등록 |
| schedule_off.command | 자동 실행 해제 |

처음 받은 파일은 맥 보안 때문에 막힐 수 있으니, 터미널에서 한 번 실행:
`xattr -dr com.apple.quarantine ~/stock_analyzer`

## 설치 (Windows / 직접 설치)
```
pip install -r requirements.txt
```

## 실행
```
python main.py --demo      # 가상 시세로 동작 확인
python main.py             # 실제 시세 (config.json 기준)
python main.py --open      # 생성 후 브라우저로 열기
python main.py --tickers 005380.KS 000270.KS NVDA --period 6mo
```
결과는 `reports/` 폴더에 `report_날짜_시간.html`(리포트)과 `summary_날짜_시간.csv`(엑셀용 요약)로 저장됩니다.

## 구성
| 파일 | 역할 |
|---|---|
| config.json | 지수·관심종목, 조회 기간, 신호 기준값 |
| data.py | 시세 수집 (yfinance → 국내 종목은 FinanceDataReader 보조) |
| indicators.py | 이동평균(5/20/60/120), RSI, MACD, 볼린저밴드, ATR, 거래량 평균 |
| universe.py | 스캔 대상 종목 목록(시총 필터)과 일괄 시세 수집·캐시 |
| scanner.py | 추천 스캔 실행·결과 저장 (앱·리포트 공용) |
| app.py, appkit/ | 주식 앱 화면 |
| strategy.py | 기법 조합 백테스트, 최고 확률 기법 선정, 매도가 최적화, 추천 |
| analysis.py | 추세 점수(-6~+6)·판정, 신호 탐지, 시황 요약 문장 |
| charts.py | 캔들·이평·밴드 / 거래량 / RSI / MACD 4단 차트, 지수 비교 차트 |
| report.py | HTML 리포트 (차트 내장 단일 파일) |
| main.py | 전체 실행 |

## 티커 표기
- 코스피: `005380.KS`, 코스닥: `035720.KQ`, 미국: `NVDA`
- 지수: `^KS11` 코스피, `^KQ11` 코스닥, `^GSPC` S&P500, `^IXIC` 나스닥, 환율 `KRW=X`

## 판정 로직
- 추세 점수: 종가의 20·60·120일선 상회 여부(±1씩), 이평 정배열/역배열(±1), 20일선 5일 기울기(±1), 최근 5일 내 골든/데드크로스·MACD 전환·52주 고저 근접(±1)
- 판정: +4 이상 강한 상승, +2 이상 상승, -2 이하 하락, -4 이하 강한 하락, 그 외 중립
- 참고 신호(점수 미반영): RSI 과매수·과매도, 볼린저밴드 이탈, 거래량 급증

## 선택 기능 — AI 시황 코멘트
`config.json`에서 `llm_commentary.enabled`를 `true`로 바꾸고 환경변수 `ANTHROPIC_API_KEY`를 설정하면 Claude가 요약 코멘트를 추가합니다. (`pip install anthropic`)

## 매일 자동 실행 (Windows 작업 스케줄러)
1. `run_daily.bat`의 경로를 실제 설치 폴더로 수정
2. 작업 스케줄러 → 기본 작업 만들기 → 매일, 평일 16:00(국내 장 마감 후) → 프로그램 시작: `run_daily.bat`

> 기술적 지표 기반 자동 분석이며 투자 권유가 아닙니다.
